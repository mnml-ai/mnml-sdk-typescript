# Security

Please report a vulnerability in this SDK or in the mnml API privately, by email to
**hello@mnml.ai** with "Security" in the subject, rather than in a public issue. Include what
you found, how to reproduce it, and the SDK version. We will reply as soon as we can.

Never put an API key, a webhook secret or any other credential in an issue, a pull request
or an example. If one is exposed, revoke it on the
[API keys](https://developers.mnml.ai/console/keys) or
[Webhooks](https://developers.mnml.ai/console/webhooks) page at once.
